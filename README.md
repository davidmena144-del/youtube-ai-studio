# YouTube AI Studio — مدير قناة مستقل

مدير ذكاء اصطناعي يدير قناة YouTube عربية بالكامل:
1. التحليل والاستراتيجية والأفكار؛
2. السيناريو والتدقيق؛
3. الصوت والفيديو والصورة المصغرة وSEO؛
4. مراجعة الجودة، ثم النشر التلقائي؛
5. تحليل النتائج وتحسين الاستراتيجية.

بعد الإعداد الأول لا يطلب موافقتك على أي فيديو. تتدخل فقط للإيقاف أو بتوجيه عام.

**صفر تكلفة إضافية:**
- **Claude:** يعمل داخل جلسات Claude Code المجدولة على اشتراكك، بلا أي مفتاح API.
- **الإنتاج:** على GitHub Actions المجاني بأدوات مفتوحة المصدر.
- **قاعدة البيانات:** Supabase المجاني.
- **النشر:** YouTube Data API المجاني.
- كل عملية ترفض العمل إن وُجد مفتاح مزوّد مدفوع.

## كيف يعمل

```
          ┌──────────── Claude Code (اشتراكك) — مهمة مجدولة ────────────┐
          │ المدير  ← agenda/preflight/lease/budget (دوال SQL)            │
          │   └─ 11 موظفًا متخصصًا (.claude/agents): تحليل، أفكار،       │
          │      استراتيجية، سيناريو، تدقيق، إخراج، صوت، صورة، SEO،      │
          │      مراجعة جودة، أداء — يُرجعون JSON والمدير وحده يحفظ      │
          └───────────────┬──────────────────────────────────────────────┘
                          │ Supabase connector (بلا أسرار في الجلسة)
                 ┌────────▼────────┐
                 │ Postgres (Supabase المجاني): ذاكرة، مهام، قرارات،     │
                 │ تقويم، سياسات، حصص — كل عملية دالة app.* ذرّية        │
                 └────────┬────────┘
                          │ اتصال TCP (سر GitHub)
          ┌───────────────▼──────────────────────────────────────────────┐
          │ GitHub Actions (مجاني): صوت عربي ← ترجمة ← مشاهد ← موسيقى ←  │
          │ FFmpeg ← صورة مصغرة ← فحص جودة ← بوابة نشر ← رفع YouTube ←    │
          │ تحليلات يومية                                                 │
          └──────────────────────────────────────────────────────────────┘
```

## البنية

```
.claude/agents/            الموظفون المتخصصون (أدوات محدودة + عقد JSON ثابت)
.claude/commands/          إجراء تشغيل المدير المجدول
drizzle/                   0000–0001 المخطط · 0002 الطابور والدوال · 0003 الأدوار · 0004 النشر · 0005 واجهة المدير · 0006 تحصين Supabase
src/core/                  السياسة، منع التكرار، حارس التكلفة، الفحص المسبق، الجدول
src/cli/studio.ts          أوامر إدارة القناة (نفس دوال SQL)
src/server/youtube/        عميل YouTube Data/Analytics + ناشر مقاوم للأعطال
src/server/worker/         معالجات الإنتاج والتحليلات
media/studio_media/        خط الإنتاج: TTS، ترجمة، مشاهد، موسيقى، تصيير، صورة مصغرة، فحص جودة
media/engines/             محركات الصوت (SILMA، Chatterbox، Piper، espeak)
media/tts-eval/            اختبار الأصوات العربية (المرحلة 2)
tests/                     Vitest على PGlite + tests/e2e على Postgres 16 + خادم YouTube وهمي
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run studio -- help` | أوامر إدارة القناة |
| `npm run studio -- pause` / `resume` | إيقاف فوري / استئناف |
| `npm run studio -- report` | ملخص: المنشور، الأخطاء، الطابور، الميزانية |
| `npm run worker:once` | العامل: إنتاج + نشر + تحليلات ثم يخرج |
| `npm test` · `npm run lint` · `npm run typecheck` | الفحوص |
| `python -m studio_media.produce --spec spec.json --out dir` | إنتاج فيديو واحد (داخل `media/`) |
