# YouTube AI Studio — مدير قناة مستقل

مدير قناة YouTube مستقل يقوده **Claude** بالكامل: البحث، والاستراتيجية، والسيناريو، والصوت، والفيديو، وSEO، والجودة، والنشر، والتحليلات. بعد الإعداد الأول لا يحتاج موافقتك على كل فيديو، وتتدخل فقط للإعداد أو للإيقاف.

**قاعدة صفر تكلفة:**
- عمل Claude يجري داخل جلسات Claude Code على اشتراكك، ولا يوجد أي مفتاح API مدفوع؛
- الوسائط تُنتج بأدوات مجانية ومفتوحة المصدر على GitHub Actions؛
- الذاكرة في Neon المجاني؛
- كل عملية ترفض العمل إن وُجد مفتاح مزوّد مدفوع.

## الحالة: المرحلة 1 (الأساس) فقط

| المكوّن | الحالة |
|---|---|
| ذاكرة القناة، والسياسات، والتوجيهات، والأفكار، والتقويم (Postgres) | ✅ مبني ومختبر |
| طابور المهام: SKIP LOCKED، وحماية الملكية، وإعادة المحاولة، والاعتمادات، والأولوية، وعدم التكرار | ✅ مختبر، منه تزامن حقيقي بـ 20 اتصالًا |
| قفل المدير، والميزانيات، وزر الإيقاف (يفشل مغلقًا)، وبوابة النشر | ✅ مبني ومختبر |
| أدوار الصلاحيات الدنيا | ✅ مختبرة على Postgres 16 |
| أداة `studio` وعامل GitHub Actions الهيكلي | ✅ مختبران عبر سائق Neon HTTP مقابل محاكٍ محلي |
| Neon الحقيقي | ⚠️ **لم يُختبر** (لا حساب بعد) |
| المدير المجدول والوكلاء المتخصصون | ⏳ P3 |
| الصوت العربي، والفيديو، والصورة المصغرة | ⏳ P2 / P4 |
| YouTube: الرفع والجدولة والتحليلات | ⏳ P5 — **لا يوجد أي نشر حقيقي حاليًا** |

## البنية

```
Claude Code (اشتراكك) ── studio CLI ──▶ Neon Postgres (الذاكرة + الطابور + دوال SQL الذرّية)
   المدير المجدول + الوكلاء (P3)                    ▲
                                                    │
GitHub Actions (مجاني) ── worker ──────────────────┘  الوسائط + YouTube (P4/P5)
```

```
src/core/          السياسة، والجدول الحتمي، ومنع التكرار، وحارس التكلفة، والفحص المسبق، وعمليات القناة
src/cli/studio.ts  طريق الكتابة الوحيد لجلسات Claude
src/server/        قاعدة البيانات، والطابور، والعامل، والتشفير، والسجل
drizzle/           0000–0001 المخطط · 0002 دوال app.* · 0003 الأدوار
tests/             Vitest على PGlite + tests/e2e (Postgres 16 عبر بروتوكول Neon HTTP)
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run studio -- help` | أوامر إدارة القناة |
| `npm run worker:once` | العامل: يفرغ مهام media/system ثم يخرج |
| `npm run db:migrate` | تطبيق الـ migrations (آمن للتكرار) |
| `npm test` · `npm run lint` · `npm run typecheck` | الفحوص |
| `OWNER_URL=… bash tests/e2e/neon-http.sh` | اختبار شامل على Postgres حقيقي |
| `npm run gen-secrets` | توليد `ENCRYPTION_KEY` |
