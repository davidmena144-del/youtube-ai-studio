# حالة المرحلة 1 — أساس مدير القناة المستقل

> التاريخ: 2026-11-15 · الفرع: `claude/channel-manager-p1` (مبني فوق PR #1 عند `1efec92`؛ PR #1 لم يُعدَّل ولم يُدمج)
> الخطة الكاملة: [`IMPLEMENTATION-PLAN.md`](IMPLEMENTATION-PLAN.md)

## الخلاصة

المرحلة 1 هي **الأساس فقط**. كل ما فيها مبني ومختبر آليًا. لكنها لا تنتج فيديو ولا تنشر شيئًا بعد.

موجود ومختبر:
- قاعدة البيانات وذاكرة القناة؛
- طابور المهام؛
- أقفال المدير؛
- منع التكرار؛
- حدود الاستهلاك؛
- زر الإيقاف؛
- صلاحيات قاعدة البيانات؛
- حارس "صفر تكلفة"؛
- أداة `studio` التي سيستخدمها Claude لإدارة القناة.

غير مبني بعد: المدير المجدول نفسه، والوكلاء المتخصصون، والصوت والفيديو، والاتصال بـ YouTube. هذه هي المراحل P2–P8.

### أخطاء حقيقية كشفها الاختبار وأُصلحت

1. **زر الإيقاف كان يمكن أن "يفشل مفتوحًا".**
   - إذا خُزنت سياسة بشكل تالف (JSON مُرمَّز مرتين، أو بلا `kill_switch`)، كانت دوال SQL تعتبر القناة غير موقوفة.
   - الإصلاح: قيد `CHECK` يمنع تخزين سياسة تالفة، ودالة `channel_paused` تعتبر أي سياسة تالفة "إيقافًا".
   - ظهر أثناء ذلك خطأ SQL كلاسيكي أيضًا: قيد CHECK الذي ينتج NULL يمرّ. أصلحته بـ `COALESCE`.
   - كلاهما مغطّى باختبار.
2. رسائل الخطأ في `studio` و`migrate` كانت تخفي السبب الحقيقي. صارت تعرض `cause`، وتعرض أخطاء التحقق حقلًا حقلًا.

### P0 — قائمة تحقق قبل أي تشغيل حقيقي (أنت تنفذها)

1. **Claude:** تأكد أن Usage credits / Extra usage **مطفأة**، ولا تضع `ANTHROPIC_API_KEY` في أي مكان.
2. **GitHub:** لا وسيلة دفع على الحساب، **أو** ميزانية Actions = $0 مع "Stop usage". عندها يتوقف التشغيل عند نفاد الحصة المجانية بدل الفوترة.
3. **Neon:** مشروع مجاني (بلا بطاقة) بفرعين `main` و`test`. الخطوات في [`SETUP.md`](SETUP.md).
4. **Google Cloud (لاحقًا في P5):**
   - مشروع مجاني؛
   - تفعيل YouTube Data API v3 وYouTube Analytics API؛
   - شاشة OAuth بحالة **In production** للاستخدام الشخصي.
5. **السياسة:** راجع القيم الافتراضية بـ `studio policy show`، وعدّل ما تريد بـ `studio policy set`.
